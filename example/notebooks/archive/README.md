# Archived notebooks (historical)

These notebooks predate the rename of the pipeline from OpenICU to WeavEHR
and of this repository from `openicu-yaib` to `weavehr-yaib`.

- They use the old OpenICU terminology, paths and variable names, and may
  import the former `openicu_yaib` package (for example
  `from openicu_yaib.transform import ...`), which no longer exists.
- They are kept unchanged as historical/reference material documenting how the
  conversion and the RICU comparison were developed. They are **not**
  maintained, linted or tested, and are not expected to run against the current
  `weavehr_yaib` package or current WeavEHR outputs.

For runnable, maintained examples use the notebooks in
[`example/datasets/`](../../datasets/) and
[`example/00_create_yaib_wide_and_compare_ricu.ipynb`](../../00_create_yaib_wide_and_compare_ricu.ipynb).
